When I process data for you

When I set up automations for your business, you are the data controller and I am the data processor. We sign a data processing agreement before the work starts.

  • The tools are registered in your name. I work with role-based access or invitation - never with shared passwords. Access is removed when the assignment is finished.
  • I only process data that is necessary for each flow. Sensitive personal data (health, social security number) are not included in the flows without written agreement and prior assessment.
  • The no-code tools are subcontractors (subprocessors). The list and storage location are documented in the data processing agreement.

When a flow uses AI to read customer messages, it is informed in the data processor agreement and you decide whether to activate it.
